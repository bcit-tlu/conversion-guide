Callouts A callout is a generic learning block for supplementary content that doesn't fit a specific category. Callouts have no icon.

Callout

Use a callout for any supplementary content that doesn't fit one of the other learning blocks.

Callout (Bordered)

Use a bordered callout when you want stronger visual emphasis without implying a specific content type.

#callout-bordered

Callout (Bordered)

Use a bordered callout when you want stronger visual emphasis without implying a specific content type.

/callout-bordered

Two callout styles are available:

  • #callout is styled like a note (soft background, no icon).
  • #callout-bordered is styled like an activity (accent top and bottom borders, no icon).

Callouts are best used sparingly. If your content fits an existing learning block (such as a note, key point, or example), use that instead so the icon reinforces its meaning.
